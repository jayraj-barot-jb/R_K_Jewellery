# R_K_Jewellery

A modern e-commerce website built with Django (Python) and PayPal as the payment processor. This project is a jewelry shop where users can browse products, add items to their cart, make secure payments via PayPal or debit/credit card, and track their orders in real time.

🌐 **Live Demo:** [https://jayraj-barot-jb.github.io/](https://jayraj-barot-jb.github.io/)

## Features

### A. Admin Users Can
1. Manage Categories (Add, Update, Filter, and Delete)
2. Manage Products (Add, Update, Filter, and Delete)
3. Manage Users (Update, Filter, and Delete)
4. Manage Orders (View and Process)

### B. Non-Registered Users Can
1. View Products (Filter based on category)
2. Explore Product Details and Related Products

### C. Registered Users Can
1. All of the Non-Registered User features
2. Add to Cart
3. Pay with PayPal or Debit/Credit Card and Order
4. See Order Status
5. See Order History
6. Update Profile
7. Change Password
8. Reset Password
